# Review checklist

- Rights confirmation precedes any remote acquisition.
- Source connector discovery does not imply reuse permission.
- Media activity worker has no X/Telegram client construction.
- DNS answers and every redirect hop are validated and pinned.
- Response bytes, time, decompression, media signature, helper-process time/output are bounded.
- Usage reservation is stable/idempotent under the media-preparation operation key.
- Media preparation and asset lineage are tenant-bound under forced PostgreSQL RLS.
- Baseline adult classification is explicitly not presented as a full visual verdict.
